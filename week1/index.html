1.1 What is Network Administration?
  • Network administration is the process of managing, maintaining, and operating a computer network to ensure its reliable performance.
  • It includes tasks such as configuring devices, monitoring traffic, troubleshooting issues, enforcing security policies, and maintaining documentation.
  • A Network Administrator (NetAdmin) is responsible for the day-to-day operations of the network infrastructure.
  • Unlike a Network Engineer who designs and builds networks, a NetAdmin maintains and optimizes them.
  • Key deliverable: a stable, secure, and efficient network environment for end-users and business operations.
1.1 Roles & Responsibilities of a Network Administrator
  • Install, configure, and maintain network hardware (routers, switches, firewalls, APs).
  • Monitor network performance and respond to alerts and alarms.
  • Manage user accounts, permissions, and access control lists (ACLs).
  • Plan and execute network upgrades and patch management.
  • Create and maintain network documentation and diagrams.
  • Enforce security policies and respond to security incidents.
  • Coordinate with ISPs and vendors for WAN connectivity and hardware procurement.
  • Provide Tier 2/3 helpdesk support for network-related issues.
1.2 FCAPS — Fault Management
  • Focuses on detecting, isolating, and correcting faults in the network.
  • Tools: SNMP traps, syslog, ping, traceroute, Nagios, Zabbix.
  • Process: Detection → Isolation → Diagnosis → Resolution → Documentation.
  • Example: A switch port goes down — syslog sends alert → admin logs in and troubleshoots → port is restored → incident logged.
1.2 FCAPS — Configuration Management
  • Tracking and managing the configurations of all network devices.
  • Includes: firmware versions, running configs, interface states, ACLs, routing tables.
  • Tools: RANCID, Ansible, CiscoWorks, manual backups via TFTP/SCP.
  • Change management: all configuration changes must be documented and approved.
  • Example: Before upgrading a router IOS, the current config is backed up to a TFTP server and a change request is filed.
1.2 FCAPS — Accounting, Performance & Security Management
  • Accounting: Tracks who uses the network, when, and how much. Used for billing in ISPs and capacity planning. Tools: NetFlow, RADIUS AAA logging.
  • Performance: Monitors bandwidth utilization, latency, jitter, and packet loss. Tools: PRTG, SolarWinds, Wireshark, SNMP polling. SLA compliance depends on this.
  • Security: Protects network from unauthorized access and attacks. Includes firewalls, IDS/IPS, 802.1X port security, VPN, and patch management. Regular audits and penetration testing.

Key Concepts & Study Notes
Important points to remember for CLO1 assessment
📌
FCAPS Acronym: Fault · Configuration · Accounting · Performance · Security — defined by ISO/IEC 7498-4 as the standard network management framework. Every network management task falls under one of these five domains.
✅
Admin vs Engineer: A Network Engineer designs and architects the network (OSI layers, subnetting, topology). A Network Administrator operates and maintains it daily. In small organisations, one person may do both — but the distinction matters in job descriptions and in this course.
⚠️
Exam tip: Questions on FCAPS often ask which category a specific task belongs to. Remember: monitoring bandwidth = Performance; blocking a port = Security; backing up configs = Configuration; tracking login times = Accounting; detecting a downed link = Fault.
🔵
Course Assessment Reminder: CLO1 is assessed via Test (15%) in Week 4. It covers Units 1 & 2 theory. Make sure your FCAPS notes are solid before the test.
