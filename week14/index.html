4.3.5 Group Discussion Guidelines
  • Each group presents their network monitoring report (10–15 minutes + Q&A).
  • All group members must contribute — allocate sections by member expertise.
  • Be prepared for questions on methodology, tools used, and recommendations.
  • Peer evaluation forms may be distributed — assess other groups fairly and constructively.
  • Professional language is expected — use correct technical terminology.
4.3.6 Preparing the Monitoring Report
  • Use the five-section structure below (matches the rubric).
  • Introduction: Network overview, monitoring objectives, tools used.
  • Methodology: How data was collected, duration, SNMP configuration details, capture setup.
  • Findings: Data tables, graphs, anomalies detected, protocol distribution.
  • Recommendations: Specific, actionable steps to improve network performance or security.
  • Conclusion: Summary of findings and whether objectives were met.
4.3.7 Final Assessment Overview
  • You will receive a Packet Tracer .pkt file with a partially configured topology.
  • Tasks typically cover: VLAN, inter-VLAN routing, static routing, DHCP, DNS, SSH.
  • Marks awarded per working configuration (connectivity test scripts may be used).
  • Save your work frequently — use Ctrl+S in Packet Tracer.
  • Bring your student ID and ensure your laptop/PC is charged.
