2.2 Static vs Dynamic Routing
  • Static routing: Routes are manually configured by an administrator. No routing protocol overhead. Best for small, simple networks or specific paths (default routes, stub networks). Does not adapt automatically to topology changes.
  • Dynamic routing: Routers automatically learn and update routes by exchanging routing information with neighbours using a routing protocol. Best for large, complex, or changing networks. Adds protocol overhead but provides automatic failover.
  • A default route (0.0.0.0/0) is a static route used to forward packets to an upstream router when no more specific route exists — commonly used for internet access.
2.2 IGP vs EGP and Protocol Overview
  • IGP (Interior Gateway Protocol): Used within a single Autonomous System (AS). Examples: RIP, OSPF, EIGRP.
  • EGP (Exterior Gateway Protocol): Used between Autonomous Systems (the internet). The only EGP in widespread use today is BGP.
  • RIP (v1/v2): Distance vector. Uses hop count as metric (max 15 hops). Simple but slow convergence. Sends full routing table every 30 seconds. Suitable only for very small networks.
  • OSPF: Link-state. Uses Dijkstra's SPF algorithm. Metric is cost (based on bandwidth). Fast convergence. Scales well. Industry-standard IGP for enterprise networks. Cisco uses OSPF heavily.
  • EIGRP: Cisco proprietary hybrid (combines distance vector and link-state). Uses DUAL algorithm. Very fast convergence. Metric considers bandwidth, delay, load, reliability.
  • BGP: Path vector protocol. The routing protocol of the internet. Used by ISPs to route between ASes. Highly scalable, policy-based routing. Complex to configure.
2.2 Administrative Distance (AD) Values
  • AD is a value (0–255) that the router uses to select the best route when multiple routing sources provide a route to the same destination. Lower AD = more trusted.
  • Connected interface: AD = 0
  • Static route: AD = 1
  • EIGRP Summary: AD = 5
  • External BGP (eBGP): AD = 20
  • EIGRP Internal: AD = 90
  • OSPF: AD = 110
  • RIP: AD = 120
  • External EIGRP: AD = 170
  • Internal BGP (iBGP): AD = 200
  • Unknown/Unreachable: AD = 255 (never used to forward traffic)
2.3 Client-Server Model and Server Types
  • The client-server model is the dominant network application architecture. Clients request services; servers provide them. The server runs continuously, waiting for requests.
  • File Server: Stores and manages files shared across the network (e.g., Windows Server with NTFS shares, Samba on Linux).
  • Print Server: Manages print queues and provides shared printer access to network users.
  • DNS Server: Resolves hostnames to IP addresses. Without DNS, users must use IP addresses directly.
  • DHCP Server: Automatically assigns IP addresses, subnet masks, default gateways, and DNS server addresses to client devices.
  • Web Server: Hosts websites and web applications, responds to HTTP/HTTPS requests (e.g., Apache, Nginx, IIS).
  • Application Server: Hosts business applications (e.g., ERP, CRM systems). Provides middleware between clients and databases.
2.3 Network Operating Systems (NOS)
  • A NOS is an OS specifically designed to support networking services, multi-user environments, centralised management, and resource sharing.
  • Examples: Windows Server, Linux (Ubuntu Server, CentOS, Debian), Novell NetWare (legacy).
  • Compared to general-purpose OS (Windows 10/11, macOS), a NOS is optimised for high availability, remote management, directory services (Active Directory), and network services.
  • Open-source NOS options: Ubuntu Server (LTS), CentOS/Rocky Linux (enterprise-grade, RHEL-compatible), Debian Server. Benefits: free, stable, large community, runs on commodity hardware, scriptable with bash/Python.
  • Hardware requirements for a server: multi-core CPU, ECC RAM, RAID storage, redundant power supplies, remote management (iDRAC, iLO, IPMI).

Key Concepts — AD Values Table & Protocol Comparison
Quick reference for exam preparation
📌
AD Memory Trick: "Silly Elephants Eat Oat Raisin Cookies" → Static(1), EIGRP-int(90), EIGRP-ext(170), OSPF(110), RIP(120), Connected(0). Lower AD wins when two protocols both have a route to the same destination.
✅
Convergence Comparison: EIGRP and OSPF converge much faster than RIP because they react to topology changes immediately (triggered updates) rather than waiting for a periodic 30-second update. RIP is considered "slow to converge" and unsuitable for large networks.
