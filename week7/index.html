3.2 Why Inter-VLAN Routing is Needed
  • VLANs create separate broadcast domains — by design, traffic cannot pass between VLANs at Layer 2.
  • To route packets between VLANs, a Layer 3 device is required (router or Layer 3 switch).
  • Scenario: PC in VLAN 10 (192.168.10.0/24) needs to reach a server in VLAN 30 (192.168.30.0/24). Without inter-VLAN routing, the packets are dropped at the switch — the destination is unreachable.
  • Three historical methods: (1) Using a separate physical router interface per VLAN — impractical (wastes ports). (2) Router-on-a-Stick — one physical link, multiple subinterfaces. (3) Layer 3 switch SVIs — the modern enterprise standard.
3.2 Method 1: Router-on-a-Stick
  • One physical router interface is connected to a switch trunk port. Multiple logical subinterfaces are created on that physical interface — one per VLAN.
  • Each subinterface is configured with: 802.1Q encapsulation for its VLAN ID, and an IP address that becomes the default gateway for that VLAN's hosts.
  • The switch port connecting to the router must be a trunk port (carries all VLAN tags).
  • Subinterface naming convention: GigabitEthernet0/0.10 (physical interface + dot + VLAN number).
  • Advantages: Simple, inexpensive (uses one router port). Disadvantages: Single link becomes a bottleneck as VLAN traffic increases. Not suitable for high-traffic environments.
  • The encapsulation dot1q <vlan-id> command is mandatory on each subinterface before assigning an IP. For the native VLAN subinterface, add the native keyword.
3.2 Method 2: Layer 3 Switch with SVIs
  • A Layer 3 switch (multilayer switch) can perform both switching and routing. It routes between VLANs internally without an external router.
  • Enable routing on the switch with the global command: ip routing.
  • Create an SVI (Switched Virtual Interface) for each VLAN: interface vlan <id> → assign IP address → no shutdown. The SVI IP becomes the default gateway for hosts in that VLAN.
  • Routing decisions are made in hardware (ASIC), making Layer 3 switches much faster than Router-on-a-Stick for inter-VLAN routing.
  • Advantages: High performance, scalable, no external router bottleneck, single device management. Disadvantages: More expensive than a Layer 2 switch — requires a multilayer switch model (Cisco 3560, 3650, 3850, Catalyst 9000 series).
3.2 Verification — show ip route and Ping Tests
  • show ip route on the router or Layer 3 switch — confirms directly connected routes for each VLAN subnet are installed (shown with C for connected and L for local).
  • Ping between PCs in different VLANs — should succeed after inter-VLAN routing is correctly configured.
  • show ip interface brief — verify that all subinterfaces (or SVIs) are up/up and have correct IP addresses.
  • traceroute from PC — shows the router's subinterface IP as the first hop, confirming the router is forwarding between VLANs.
  • If ping fails: check (1) subinterface encapsulation VLAN ID matches switch VLAN IDs, (2) PC default gateway matches subinterface IP, (3) trunk port allows the VLAN, (4) SVI is not shutdown.

Cisco IOS — Inter-VLAN Routing Configuration Examples
Both methods: Router-on-a-Stick and Layer 3 Switch SVIs
🔵
Scenario: Three VLANs — VLAN 10 (SALES: 192.168.10.0/24), VLAN 20 (IT: 192.168.20.0/24), VLAN 30 (FINANCE: 192.168.30.0/24). Router connected to switch via a trunk link.

Method 1 — Router-on-a-Stick (on the Router):

! ── Prerequisite: SW1 G0/1 configured as trunk (see Week 6 config) ──

! ── On the router: bring up the physical interface (no IP on physical) ──
Router(config)# interface GigabitEthernet0/0
Router(config-if)# description Trunk link to SW1
Router(config-if)# no shutdown
Router(config-if)# exit

! ── Subinterface for VLAN 10 (SALES) ──
Router(config)# interface GigabitEthernet0/0.10
Router(config-subif)# description VLAN 10 - SALES Gateway
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0
Router(config-subif)# exit

! ── Subinterface for VLAN 20 (IT) ──
Router(config)# interface GigabitEthernet0/0.20
Router(config-subif)# description VLAN 20 - IT Gateway
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0
Router(config-subif)# exit

! ── Subinterface for VLAN 30 (FINANCE) ──
Router(config)# interface GigabitEthernet0/0.30
Router(config-subif)# description VLAN 30 - FINANCE Gateway
Router(config-subif)# encapsulation dot1Q 30
Router(config-subif)# ip address 192.168.30.1 255.255.255.0
Router(config-subif)# end

! ── Verify ──
Router# show ip route
Router# show ip interface brief
Router# wr

Method 2 — Layer 3 Switch SVIs:

! ── On a Layer 3 switch (e.g., Cisco 3560 or 3650) ──
! ── Prerequisite: VLANs 10, 20, 30 already created (see Week 6) ──

! ── Step 1: Enable IP routing on the switch ──
L3Switch(config)# ip routing

! ── Step 2: Create SVI for VLAN 10 ──
L3Switch(config)# interface vlan 10
L3Switch(config-if)# description VLAN 10 SALES Gateway
L3Switch(config-if)# ip address 192.168.10.1 255.255.255.0
L3Switch(config-if)# no shutdown
L3Switch(config-if)# exit

! ── Step 3: Create SVI for VLAN 20 ──
L3Switch(config)# interface vlan 20
L3Switch(config-if)# description VLAN 20 IT Gateway
L3Switch(config-if)# ip address 192.168.20.1 255.255.255.0
L3Switch(config-if)# no shutdown
L3Switch(config-if)# exit

! ── Step 4: Create SVI for VLAN 30 ──
L3Switch(config)# interface vlan 30
L3Switch(config-if)# description VLAN 30 FINANCE Gateway
L3Switch(config-if)# ip address 192.168.30.1 255.255.255.0
L3Switch(config-if)# no shutdown
L3Switch(config-if)# end

! ── Verify ──
L3Switch# show ip route
L3Switch# show ip interface brief
L3Switch# show interfaces vlan 10
L3Switch# wr

🖥️ Lab 3 — Inter-VLAN Routing using Router-on-a-Stick

Topology: 1 Cisco Router (ISR4321) + 1 Cisco 2960 Switch. 6 PCs (2 per VLAN: VLAN 10, 20, 30). Router Gi0/0 connected to Switch G0/1 (trunk). Start with the completed Week 6 switch configuration.

  1. Load the Week 6 saved topology or rebuild it: 1 Router + 1 Switch + 6 PCs. Connect Router Gi0/0 to Switch G0/1 using a straight-through cable.
  2. On the switch (if not done from Week 6): confirm VLANs 10, 20, 30 exist. Confirm access port assignments. Configure G0/1 as a trunk: switchport mode trunk, allowed VLANs 10,20,30. Verify with show interfaces trunk.
  3. On the router — bring up the physical interface: interface GigabitEthernet0/0 → no shutdown (do NOT assign an IP to the physical interface).
  4. Create subinterface GigabitEthernet0/0.10: encapsulation dot1Q 10 → ip address 192.168.10.1 255.255.255.0. This is the default gateway for VLAN 10 hosts.
  5. Create subinterface GigabitEthernet0/0.20: encapsulation dot1Q 20 → ip address 192.168.20.1 255.255.255.0. Create subinterface GigabitEthernet0/0.30: encapsulation dot1Q 30 → ip address 192.168.30.1 255.255.255.0.
  6. Verify the router: run show ip route — confirm routes for 192.168.10.0/24, 192.168.20.0/24, 192.168.30.0/24 appear as directly connected (C). Run show ip interface brief — all subinterfaces should be up/up.
  7. Configure all 6 PCs with IP addresses in their VLAN subnets and set the correct default gateways: VLAN 10 PCs → gateway 192.168.10.1; VLAN 20 PCs → gateway 192.168.20.1; VLAN 30 PCs → gateway 192.168.30.1.
  8. Test connectivity: (a) Ping from a VLAN 10 PC to a VLAN 10 PC (same VLAN — should work). (b) Ping from a VLAN 10 PC to a VLAN 20 PC (different VLAN — should now work via the router). (c) Ping from VLAN 10 to VLAN 30. (d) Run traceroute and confirm the router subinterface IP appears as the first hop. Save all configurations.

Key Concepts & Study Notes
Critical points for CLO2 practical assessment
📌
Router-on-a-Stick Critical Rule: The physical router interface must be no shutdown but must NOT have an IP address assigned. The IP addresses are on the subinterfaces only. The encapsulation dot1Q <vlan-id> command on each subinterface tells the router which VLAN tag to process.
✅
Layer 3 Switch advantage: With a Layer 3 switch, routing is performed in hardware (ASIC) at wire speed. With Router-on-a-Stick, all VLAN traffic must traverse the single trunk link to the router and back — this creates a bottleneck. For high-throughput environments, always use a Layer 3 switch.
⚠️
Common Lab Mistake: Setting the PC's default gateway to the wrong subinterface IP. VLAN 10 PCs must have gateway 192.168.10.1 (the VLAN 10 subinterface), NOT 192.168.20.1 or any other. Each VLAN has its own subnet and its own gateway (the subinterface IP on the router).

Inter-VLAN Routing: Method Comparison
Router-on-a-Stick vs Layer 3 Switch
🔀 Router-on-a-Stick
  • Inexpensive — uses a standard router
  • Easy to understand and configure
  • Good for small networks / labs
  • Single link bottleneck
  • Software routing — slower than ASIC
  • Not scalable for high traffic
🔄 Layer 3 Switch (SVIs)
  • Hardware ASIC routing — very fast
  • Highly scalable for enterprise
  • No external router bottleneck
  • Single device management
  • More expensive than Layer 2 switch
  • Requires multilayer switch model
