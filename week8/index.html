3.3.1 Static Routing Fundamentals
  • Static routes are manually configured paths — no routing protocol overhead.
  • Syntax: ip route <network> <mask> <next-hop-ip | exit-interface>
  • Administrative distance = 1 (most trusted after connected routes).
  • Best suited for stub networks and small topologies.
  • Floating static route: set AD higher (e.g. 10) to serve as a backup.
3.3.2 Default Static Route (Gateway of Last Resort)
  • Command: ip route 0.0.0.0 0.0.0.0 <next-hop>
  • Matches ANY destination that has no more specific route.
  • Commonly used at stub routers connecting to the ISP.
  • Appears in routing table as S* (candidate default).
3.3.3 RIPv2 Configuration
  • Distance-vector protocol; maximum hop count = 15 (16 = unreachable).
  • RIPv2 supports VLSM and sends subnet masks in updates (classless).
  • Must use no auto-summary to prevent route summarisation to classful boundaries.
  • passive-interface stops RIP hellos on user-facing ports — improves security.
  • Update timer: 30 s · Invalid: 180 s · Flush: 240 s.
3.3.4 Verification Commands
  • show ip route — view the routing table; look for S (static) and R (RIP) entries.
  • show ip protocols — confirm RIP version, advertised networks, timers.
  • debug ip rip — live RIP update messages (disable after use!).
  • ping <ip> — end-to-end connectivity test.
💡
Key Concepts
ℹ️
Static vs Dynamic: Static routes give full control but require manual updates when topology changes. Dynamic protocols like RIPv2 adapt automatically but consume bandwidth with periodic updates.
✅
Tip — no auto-summary: Always enter no auto-summary in RIPv2 when using discontiguous subnets or VLSM. Without it, RIPv2 behaves like RIPv1 and summarises to classful boundaries.
⚠️
Routing Loops: RIP uses split-horizon, poison reverse, and hold-down timers to prevent routing loops. Maximum hop count of 15 is an additional safeguard.
🔧
Cisco IOS Shortcut: You can use the exit interface name instead of a next-hop IP for point-to-point links: ip route 10.0.0.0 255.255.255.0 Serial0/0/0

Cisco IOS Configuration Examples
Static routes on 2-router topology; RIPv2 on 3-router topology

Example 1 — Static Routes (R1 ↔ R2 topology)

! ── R1: 192.168.1.0/24 ── Gi0/0 ── [R1] ── Se0/0/0 ── [R2] ── Gi0/0 ── 192.168.2.0/24
! Configure static route on R1 to reach R2's LAN
R1(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2

! Configure static route on R2 to reach R1's LAN
R2(config)# ip route 192.168.1.0 255.255.255.0 10.0.0.1

! Default static route on R1 pointing to ISP
R1(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1

! Verify
R1# show ip route

Example 2 — RIPv2 (3-router topology: R1–R2–R3)

! ── Configure RIPv2 on R1
R1(config)# router rip
R1(config-router)# version 2
R1(config-router)# network 192.168.1.0
R1(config-router)# network 10.0.0.0
R1(config-router)# no auto-summary
R1(config-router)# passive-interface GigabitEthernet0/0

! ── Repeat on R2 and R3 with their respective networks
R2(config)# router rip
R2(config-router)# version 2
R2(config-router)# network 10.0.0.0
R2(config-router)# network 10.1.0.0
R2(config-router)# no auto-summary

! ── Verify RIPv2 operation
R1# show ip protocols
R1# show ip route
! Look for R (RIP) entries in the routing table
