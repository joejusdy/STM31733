Sub-topic Detail
Expand each section to study
3.4.1 DORA Process
  • Discover: Client broadcasts to find a DHCP server (src 0.0.0.0, dst 255.255.255.255).
  • Offer: Server unicasts/broadcasts an IP address offer.
  • Request: Client broadcasts acceptance of the offer.
  • Acknowledge: Server confirms — client can now use the IP address.
  • DHCP uses UDP port 67 (server) and 68 (client).
3.4.2 Configuring a DHCP Pool
  • ip dhcp pool <name> — creates and enters DHCP pool config mode.
  • network <network> <mask> — defines the address pool range.
  • default-router <ip> — sets the gateway handed to clients.
  • dns-server <ip> — DNS server(s) pushed to clients.
  • lease <days> [hours] [minutes] — lease duration (default 1 day).
3.4.3 Excluded Addresses & Verification
  • ip dhcp excluded-address <low> [high] — prevents these IPs from being leased.
  • Always exclude router interfaces, servers, printers, and other static devices.
  • show ip dhcp binding — lists all current client leases.
  • show ip dhcp pool — pool stats including leases in use and available.
  • show ip dhcp conflict — IPs that caused address conflicts.
3.4.4 DHCP Relay Agent
  • DHCP broadcasts cannot cross router boundaries by default.
  • The relay agent forwards DHCP broadcasts as unicast to the centralised DHCP server.
  • Configured on the router interface facing the clients.
  • Command: ip helper-address <dhcp-server-ip>
  • Enables a single DHCP server to serve multiple VLANs/subnets.
💡
Key Concepts
ℹ️
DHCP Lease: The lease time determines how long a client keeps its IP. Short leases suit guest networks; longer leases suit stable office environments. Default on Cisco IOS is 1 day.
✅
Always exclude before defining pool: The ip dhcp excluded-address command must appear before the ip dhcp pool commands in the config (or at least before clients request leases).
⚠️
IP Conflicts: If a client manually sets an IP that is in the DHCP pool, a conflict will occur. Run show ip dhcp conflict and clear ip dhcp conflict * to resolve.
🔧
Relay Agent Placement: ip helper-address goes on the client-side interface (sub-interface or physical) of the router — NOT on the interface facing the DHCP server.

Cisco IOS Configuration Examples
Full DHCP server, exclusions, and relay agent

Example 1 — Full DHCP Server on a Router

! ── Exclude the first 10 addresses (router, servers, printers)
Router(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.10

! ── Create DHCP pool for LAN_USERS
Router(config)# ip dhcp pool LAN_USERS
Router(dhcp-config)# network 192.168.1.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.1.1
Router(dhcp-config)# dns-server 8.8.8.8 8.8.4.4
Router(dhcp-config)# lease 7
Router(dhcp-config)# exit

! ── Verify
Router# show ip dhcp pool
Router# show ip dhcp binding

Example 2 — DHCP Relay Agent

! ── On the branch router, interface facing clients
BranchR(config)# interface GigabitEthernet0/0
BranchR(config-if)# ip address 10.10.10.1 255.255.255.0
BranchR(config-if)# ip helper-address 192.168.100.10
BranchR(config-if)# no shutdown
! 192.168.100.10 = centralised DHCP server address
